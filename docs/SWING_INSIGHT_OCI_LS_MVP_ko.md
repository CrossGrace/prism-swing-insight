# OCI홀딩스 · LS ELECTRIC: 독립 0~3거래일 스윙 연구 및 모의매매 (MVP)

## 목적과 승인된 범위

- 종목은 수동 지정한 **OCI홀딩스(010060)** 및 **LS ELECTRIC(010120)** 2개로 한정한다. 자동 종목 발굴은 하지 않는다.
- 보유기간은 **진입일(0일)부터 3거래일 후까지**다. 본선 PRISM의 추세추종 매매 로직과 별도 `swing_insight/` 패키지다.
- **과거 일봉 연구 재생(`simulate`)**, **MCP 시세·뉴스/공시 논리 점검(`review`)**, **회계상 수동 가상체결(`paper-fill`)**만 제공한다. 실주문, 기존 전략 자동 전환, 브로커 주문 API는 없다.
- PRISM의 `kospi_kosdaq` **MCP** 서버에서 `get_stock_ohlcv`, `get_index_ohlcv`를 재사용한다. 뉴스는 PRISM 기존 뉴스 문맥, 재무는 기존 WiseReport 연간 실적 파서를 선택적으로 호출한다. OpenAI 분석은 `OPENAI_API_KEY` 및 명시적 `--model`이 있을 때만 호출한다.

| LS ELECTRIC | [LS그룹 공식 2026-10-19 보도자료](https://www.lsholdings.co.kr/ko/media/news/772b59747344736435426636425a765a366a557358417454414c477747506665): 북미 데이터센터 장기 공급계약 발표 | 수주잔고와 수익 인식 시차, 수익성·고평가 여부·테마 변동성 |

**LTA는 중장기 계약이라는 확인된 사실이지, 0~3거래일의 지지선이나 주가 하방보장을 의미하지 않는다.** `저평가`, `시장의 낮은 관심`, `상방 모멘텀` 또한 이 자료만으로는 확증하지 않는다. 실제 가치 판단을 추가하려면 해당 시점의 재무·밸류에이션·거래대금 시계열이 필요하다.

사용자가 언급한 **MSI**는 정의/제공처를 확인하기 전까지 매매 조건에 포함하지 않는다. 국내에서는 뉴시스·코스콤의 [시장심리지수(MSI)](https://twww.newsis.com/msi/whatmsi/)도 존재한다. 아래 **RSI(상대강도지수)는 MSI와 다른 지표**이며, 코드의 RSI 기반 신호는 단지 재현 가능한 *초기 비교 가설*이다. 이후 MSI 원천·발표시각·과거 보존 데이터가 확보되면 같은 시점 정보만 사용하여 별도 전략으로 실험한다.

## 빠른 실행

1. 기존 PRISM 의존성 및 KIS 시세 조회용 MCP 설정을 완료한다. `examples/swing_watchlist_oci_ls.json`은 근거·인용 URL이 포함된 출발용 설정이다. 실제 분석 전에는 원문과 시각을 재확인한다.
2. **과거 일봉 재생**: 다음 숫자는 *예제 실험 변수*일 뿐 추천 설정/성과가 아니다. 수수료·세율·슬리피지는 실행 환경에 맞게 사용자가 지정해야 한다. 최종 날짜는 당일 장중 봉의 혼입을 막기 위해 KST 기준 전날 이하여야 한다.

```bash
python -m swing_insight simulate \
  --watchlist examples/swing_watchlist_oci_ls.json \
  --start 2026-01-01 --end 2026-11-18 \
  --rsi-ceiling 45 --dip-pct 2 \
  --stop-pct 3 --take-pct 5 --max-hold-days 3 \
  --fee-bps 10 --sell-tax-bps 20 --slippage-bps 10
```

결과는 종목별 거래 이력, 총 거래 횟수, 승률, 평균/최악 순수익률(거래당 %)이다. **포트폴리오 전체 누적 수익률이나 실현손익은 아니다.** 거래가 없으면 승률·평균은 `null`이다. 과거 LTA 발표 이전의 시세에는 현재의 장기 공급계약 가설을 소급해 적용하지 않는다. 위 설정에서는 가장 최근 등록 근거 공개일이 각 종목의 첫 신호 허용일이다.

3. **현재 시점 논리 검토 및 누적 기록**(시장 데이터는 완성된 거래일을 지정):

```bash
python -m swing_insight --db runtime/swing_insight.sqlite review \
  --watchlist examples/swing_watchlist_oci_ls.json \
  --as-of 2026-11-18 --model YOUR_OPENAI_MODEL --news
```

`--fundamentals`는 **실행일과 `--as-of`가 같은 날에만** 현시점 WiseReport 연간 실적을 수집한다. 과거 특정 날짜의 재무 공시를 오늘 웹페이지로 대체하지 않는다. 비밀키는 환경변수로 주고, JSON 기록에는 저장하지 않는다. LLM 분석이 빠지거나 근거 ID를 검증할 수 없으면 `UNKNOWN`이 된다.

4. **수동 가상장부**(자금·단일 종목 한도·총한도·비용을 *사용자가 직접 결정*한 뒤 1회 생성):

```bash
python -m swing_insight --db runtime/swing_insight.sqlite paper-init \
  --capital YOUR_CASH --single-limit YOUR_PER_STOCK_FRACTION \
  --total-limit YOUR_TOTAL_EXPOSURE_FRACTION \
  --fee-bps YOUR_FEE_BPS --sell-tax-bps YOUR_SELL_TAX_BPS
```

검토된 종목만 `paper-fill`로 임의의 **종가 참조 가상기록**을 남길 수 있다. 이는 진짜 미래형 체결/호가 검증이 아니라는 점에 유의한다. `paper-fill --help` 참조. 모의 거래 성과를 평가할 때에는 반드시 위 `simulate`의 **다음날 시가 모델**을 사용한다. 장부는 운영 실험용이며 성과 증빙으로 사용하지 않는다.

## 과거 재생의 기법과 방어장치

- 신호일 **T 종가까지** 확인한 RSI(14), 최근 3거래일의 하락 및 당일 반등 조건으로만 후보를 만든다. **진입은 다음 거래일 T+1 시가**에서 불리한 슬리피지를 적용한다.
- 신호일 KOSPI 일봉의 PRISM `MarketPulse` 상태가 `UPTREND`인 경우에만 가상 진입을 허용한다. `UNDER_PRESSURE`·`CORRECTION`·지수/종목 자료 누락이면 진입 불가다. 시장 급락 시 *신규 진입 금지*이며 기존 포지션의 수익을 보장하는 자동 헤지는 아니다.
- 진입일(보유 0일)부터 고가·저가로 손절/익절을 가정한다. 동일 일봉에서 손절·익절이 모두 닿으면 손절 선행으로 처리한다. 손절 갭하락은 손절가가 아닌 **시가**에 판다. 그 외 장중 호가·체결순서를 모르는 OHLC 시뮬레이션의 한계가 남는다.
- 최대 보유일에 종가 기준으로 종료한다. 남은 일봉이 부족한 미완료 거래를 미래 가격으로 억지 청산하지 않고 통계에서 제외한다.
- 시세는 수정주가/거래량 필요. 검증 실패·OHLC 모순·미확인 출처·미래 날짜는 실패/진입 차단. 공시·IR 근거에는 공개 날짜를 붙여 발표 전에 본 것처럼 적용하지 않는다.
- 모형은 종목별 독립 거래 집계이며 동시 포지션 현금 배분/유동성·호가 잔량·미끄러짐의 급변·시장가 충격/체결가능성까지 재현하지 못한다. 당일 청산은 분봉이 없어 **정밀한 초단타 전략과 다르다**.

## 2026년 9월~11월 가격·RSI만 본 최초 눈가림 재생

데이터: [한국주식데이터/금융위원회 공공데이터 기반 일별 시세](https://aikstockdata.com/downloads/history), **2026-11-17 마감 확정분**. 제공자료의 비영리 인용·재현 조건을 확인해야 하며, 원본을 저장소에 넣거나 상업적으로 재배포하지 않는다. 11월 18일 이후의 봉을 포함하지 않는다.

- 사전에 문서에 적었던 실험 변수 그대로: **RSI14 ≤ 45, 최근 3거래일 등락률 ≤ -2%, 당일 종가 반등**. T 종가 신호 → 다음 거래일 시가에만 진입.
- 손절 -3%, 익절 +5%, 최대 보유 3거래일; 매수/매도 수수료 10bp씩, 매도 세금 20bp, 매수·매도 슬리피지 각각 10bp(실제 브로커 과금 규칙이 아니라 고정 실험 가정).
- 사용자 시나리오대로 **코스피를 항상 UPTREND라고 강제**하고, 9월 당시 알 수 없던 10월 LTA는 신호에 사용하지 않는다. 이 모드는 실제 시장 위험 필터를 검증하지 않는다.

### 재현 명령

```bash
python -m swing_insight simulate \
  --watchlist examples/swing_watchlist_oci_ls.json \
```
